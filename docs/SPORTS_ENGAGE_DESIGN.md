## 1. 인과 — 왜 이걸 원하나 (원인 → 행동 → 결과)

```
업자방 멤버 = 스포츠 경기에 관심(돈이 걸린 사람 많음)
  └─ 경기 중엔 점수를 계속 확인하고 싶음 ─┐
                                          ├─ 앱(라이브스코어)을 따로 켬 → 방을 떠남 → 방이 조용해짐  ✗ (방장 손해)
                                          └─ 방에 점수가 바로 뜸 → 방에서 같이 떠듦 → 방이 살아남  ✓ (방장이 원하는 것)
방장(고객) = 방 활동 = 자기 사업 홍보 효과
  └─ 매일 들어오게 할 이유 필요 → 출석·복권·운세·오늘의 경기·순위
```
→ **진짜 목표 = 방 활동(머무는 시간·말 수)을 늘리는 것.** 스포츠 알림·출석·복권·랭킹은 전부 그 수단.
→ 그래서 성공 기준도 "알림이 갔다"가 아니라 **"알림 뒤 방에서 사람들이 말을 했다"** (§7 측정).

### 실패의 인과 (지금까지 왜 '실시간 알림이 문제'였나)
| 겉으로 본 것 | 진짜 원인 | 고침 |
|---|---|---|
| "실시간 득점 알림은 안 돼" | 경기 하나 알림 기능이 없었음 → AI 가 낱말 알림 규칙을 만들거나 거절 | ✅ sports alert (10-10) |
| "1:1 먼저 열어" | 멤버 요청은 1:1 로만 보내게 설계 | ✅ 방에 바로 (10-11) |
| "생테티엔" 못 찾음 | 2부 리그 팀이 이름표에 없음 + 한국어로만 찾음 | ✅ 세계 축구 + 영어 이름 (10-11) |
| "예정 경기라 못 걸어" | 우리 도구가 못 찾자 AI 가 웹 검색 → 현지 시각을 잘못 읽음 | 🔜 도구가 못 찾으면 '못 찾음'만, 일정은 도구 결과만 믿기 |
| 알림이 늦음 | 60초마다 확인 (ESPN 은 7초마다 새로 냄) | ✅ 8초 (10-10) |
| 말해야만 옴 | 방 구독이 0개 (서버: sports_follow 0줄) — 아무도 설정을 안 함 | 🔜 **§3 A 자동 라이브** |

## 2. 원칙

1. **설정 없이 기본으로 된다** — 방에 소담이 있으면 큰 경기는 알아서 (단, 도배 X: 경기당 카드 1장을 고쳐 쓰기).
2. **말 = 버튼 = 명령, 한 길** — "득점하면 알려줘" · [🔔] 버튼 · `.알림` 이 전부 같은 함수(`sports.alerts.watch`)로. AI 는 말을 그 함수로 옮기기만.
3. **조건으로 막지 않는다** — "1:1 먼저", "관리자만" 대신 가능한 쪽으로 바로 (멤버 → 방에 경기 하나, 계속 알림만 관리자).
4. **지어내지 않는다** — 점수·일정은 도구 결과만. 못 찾으면 못 찾았다고 + 버튼으로 다른 길.
5. **돈은 안 건다** — 맞히기·복권은 점수·경품(방장이 직접 줌). 배당·베팅 없음.

## 3. 기능 설계

### A. ⚡ 자동 라이브 (말 안 해도 옴) — 1순위
- 방 설정 `sports_auto`: `off` / `big`(주요 리그) / `follow`(구독한 리그·팀만). **기본값 정책**: 이미 스포츠를 켠 방 = 그대로, 새로 켜는 방은 빠른 설정 마법사에서 '⚡ 큰 경기 자동' 한 번 누르면. (13개 방 전부에 갑자기 쏟아지면 도배 → 방장 한 번 동의)
- `big` 리그 = 업자방이 많이 보는 것: EPL·라리가·세리에A·분데스·리그1·챔스·유로파·MLB·NBA·NHL·KBO·K리그 (오너가 바꿀 수 있게 상수).
- **라이브 카드** (Fotmob-Updates-Bot·ucl-live-bot 방식): 경기 시작 때 방에 카드 1장 → 8초마다 그 카드를 **고쳐 씀**(점수·분·득점자). 골·종료만 새 글(폰 알림이 울리게). 카드 버튼 `[📩 1:1로도] [🧠 분석] [🎯 맞히기(시작 전)] [🔕 이 경기 끄기]`.
- 도배 방지: 방마다 동시에 카드 **최대 4장**(큰 경기 우선 = 리그 순위), 텔레그램 수정 한도(방마다 분당 20) 안에서 — 점수 바뀜은 바로, 분만 바뀐 건 30초에 한 번. 조용한 시간엔 카드 안 띄움.
- 경기 전 15분 "곧 시작" 한 줄 + [🎯 맞히기] (WroxExM 방식).

### B. 🔔 알림 걸기 — 말·버튼 통합 (일부 완료)
- AI 도구 `sports alert` · 1:1 [🔴 라이브]의 🔔 · 카드 버튼 → 같은 `watch()`.
- 못 찾으면: 후보 경기 버튼 3개 ("이 경기 맞아요?") — 영어 이름 몰라도 고를 수 있게.
- 지도·도구 설명: "경기 일정·시각은 sports 결과만, 없으면 web_search 결과를 '확인 필요'로" (생테티엔 오보 막기).

### C. 📱 1:1 후바오식 홈 (일부 완료)
- 맨 위 카드에 **나의 통계**(승률·누적·주간 순위) + **나의 알림** 목록 (후바오 화면 그대로) → 버튼 줄: 🔴 Live · 🧠 분석·오늘의 픽 · 🔔 스코어 알림 · 📅 전체 일정 · 🏆 추천픽 랭킹 · 📅 출석 · 🔮 운세.
- '오늘의 픽' = 오늘 큰 경기 3개의 AI 분석 묶음 (경기당 캐시 공유라 비용 작음).

### D. 📅 출석 → 🎟 복권 → 🎁 경품 (FOX 요청)
- `.출석`(이미 포인트 게임에 있음 — **소담 출석과 분리**: 출석 = 하루 1번 복권 1장, 포인트와 무관).
- 복권 긁기 버튼 `[🎟 긁기]` → 당첨 확률·경품·주간 당첨 상한은 **방 설정**(방장이 정함: 기본 1% · 주 2명 · 경품 글 '커피 기프티콘'). 당첨 = 방에 축하 + 방장 1:1 "경품 보내 주세요(누구·무엇)" + 당첨 기록. **경품은 방장이 직접**(소담은 돈·쿠폰을 주지 않음).
- 공정성: 확률은 서버 `secrets`, 주간 상한은 DB 한 문장으로 차지(동시에 눌러도 상한 초과 X), 당첨 기록 공개(`.복권당첨`).
- 출석 연속일·이번 달 출석 순위(활동 장치).

### E. 🔮 오늘의 운세
- 사람·날짜로 고정되는 운세(같은 날 다시 물어도 같음) — 템플릿 조합(재물·연애·건강·행운 숫자·행운 팀). AI 안 씀(비용 0) 또는 하루 한 번 AI 문장(선택).

### F. 📏 채팅 집계 '5글자 이상 · 도배 X'
- 5글자는 완료(chat_min_chars). **도배 X** = 같은 사람이 같은 글을 10분 안에 반복한 것·관리로 지워진 글 제외 → `db.MIN_CHARS` 옆에 '반복 제외' 조건(설정 `chat_no_repeat`).
