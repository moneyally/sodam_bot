## 0. 텔레그램이 봇에게 주는 것 (근거)
- 방 참가자 전체: Bot API 는 안 줌 → **MTProto 봇 세션** `channels.getParticipants` ("Both users and bots can use this method", 봇이 관리자여야 함).
  Recent 필터는 **최대 1만 명**. 이미 `mtproto.participants()` 가 있음 (지금은 이름 순찰에만 씀).
- 소개글: `users.getFullUser` (봇 가능) → `full_user.about`, `common_chats_count` 등. **사람마다 요청 1번** → 명단 전체엔 안 씀(FloodWait), 한 사람 프로필에만.
- 접속 시간: 참가자 목록의 `user.status`
  - `UserStatusOnline/Offline(was_online)` = 정확한 시각
  - `Recently`(1~3일)·`LastWeek`·`LastMonth` = 대략 (상대가 '마지막 접속' 숨김)
  - `UserStatusEmpty`/없음 = **"오래전" 또는 "봇이라 못 봄" — 구분 불가**
  - 봇 세션에 실제로 무엇이 오는지는 문서로 확인 못 함 → 첫 스캔이 **분포를 재서 보여줌** (정확·대략·모름 몇 명).
- 탈퇴 계정: `user.deleted` (확실). 텔레그램 자체 표시: `scam`·`fake` 딱지.

## 2. 프로필 카드 (`.프로필`)
- 텔레그램: 이름·@아이디(여러 개)·숫자 ID·계정 생성 추정(`accountage`)·**소개글**·**접속 상태**(정확 시각 / 대략 / 숨김)·프리미엄·프사 유무·공통 방 수·`scam/fake/탈퇴` 딱지
- 이 방 기록(소담): 처음 본 날·입장일·마지막 글·글 수(7일/전체)·경고·제재·이름 변경 수 — `insight.member_timeline` 재사용
- 소개글·이름은 남이 쓴 글 → HTML 이스케이프, 길이 자름. getFullUser 결과 **1시간 캐시**, 사람당 1분 1번.

## 3. 멤버 정리 흐름
1. **스캔**: `participants()` (1만 명 넘으면 `partial` 표시 — 받은 사람만 대상). 방당 10분에 1번, 결과 DB 저장(30분 유효).
2. **분류** (한 사람이 여러 분류 가능, 요약은 분류별 인원):
   - 🪦 탈퇴 계정 — `deleted`
   - 🤖 다른 봇 — `is_bot` (소담 자신·방 관리자 봇 제외)
   - 💤 잠수 N일 — **정확 시각**(`Offline.was_online`)이 N일보다 전 **이고** 소담 기록상 N일 안에 글·반응 없음.
     `LastMonth` 는 30일 안 접속이라 잠수 30 에 안 넣음. `Empty/모름` 은 **별도 "접속 모름"** — 기본 체크 안 됨.
   - 👻 가라 의심 — 점수(아래 모두 사실만): 소담 기록상 글 0개 · 프사 없음 · @아이디 없음 · 계정 최근 생성 · 같은 10분에 5명 넘게 무더기 입장 · 접속 대략/모름.
     3개 이상 = 의심. **확정 아님** 문구. 기본 체크 안 됨.
3. **보호 (절대 안 내보냄)**: 방 관리자·오너·봇 관리자·소담 자신·free 멤버·제외 명단·**최근 14일 안에 이 방에서 글 쓴 사람**(접속 상태가 뭐라든).
4. **미리보기**: 분류 선택(여러 개) → 인원·앞 20명 이름 → [📄 전체 명단 CSV] → [🧹 N명 내보내기] → **확인 카드**(누른 사람이 여전히 관리자·ban 권한인지 다시 확인).
5. **실행(뒤에서)**: 한 명씩 `ban → unban`(= 킥, 다시 들어올 수 있음). 사람마다 직전에 `getChatMember` 로 **아직 멤버·관리자 아님** 확인.
   - 속도: 1.2초에 1명, `RetryAfter` 면 그만큼 쉼. 진행 메시지 20명마다 수정. 방마다 작업 1개(두 관리자가 동시에 못 돌림).
   - 재시작해도 이어서: 작업·남은 명단 DB 저장, 시작 때 이어 돌림.
   - [⏸ 중지] 버튼·`.멤버정리 중지`.
6. **부작용 막기** (작업 중인 방):
   - 킥으로 생기는 "~님이 ~를 내보냄" 서비스 메시지 → 지움
   - 👋 작별 인사·이상징후(대량 이탈)·입장/퇴장 알림 규칙 → 이 작업이 낸 퇴장은 건너뜀
   - 관리 기록: 한 사람씩 `kick`(사유 "멤버 정리: 탈퇴 계정") + 요약 1줄
7. **끝 보고**: 내보냄 N · 이미 나감 M · 실패 K(이유) · 걸린 시간. 방 인원 전후.

## 4. 깊은 버그 막기 체크
- 미리보기와 실행 사이에 명단이 바뀜 → 실행 때 사람마다 다시 확인.
- 스캔이 1만 명에서 잘림 → '나감' 판단 안 함, 받은 사람만.
- 접속 상태 '모름'을 '오래전'으로 착각 → 잠수엔 정확 시각만.
- 소담이 이 방에 들어오기 전 기록은 없음 → '글 0개'는 **소담이 본 기간** 표시("09-22 부터 기록").
- 확인 카드 재사용·다른 사람이 누름 → 만든 사람만, 한 번만, 만료 10분.
- 봇 권한 없음(ban) → 시작 전 확인, 도중에 권한 빠지면 멈추고 알림.
- FloodWait(MTProto)·RetryAfter(Bot API) → 기다리거나 멈춤, 무한 재시도 X.
- 수천 명 → 메모리·DB 쪽수 처리, 진행 메시지 수정 빈도 제한.
- 방에 명단 안 뿌림 (개인정보) — 결과는 관리자 1:1, CSV 도 1:1.
- 방 인원이 확 줄어듦(가라) → 확인 카드에 "방 인원 약 N → M" 표시.
