## 라우팅 설계
- `menu.py` 에 `ROUTES = {코드: Route(handler, need)}`, need = PUBLIC / ADMIN / TG_ADMIN(텔레그램 관리자+오너, bot_admin 제외) / OWNER.
- 순서: 1:1 인지 확인 → 콜백 레이트리밋(40/분) → 엄격 파싱(알려진 코드, cid `^-\d{5,20}$`, chats 에 존재) → 매번 권한 확인
  (결제·기간 부여·삭제·자료 업로드는 캐시 무시하고 새로 확인) → 핸들러가 `Screen(text, kb, toast)` 반환, 라우터가 q.answer 정확히 1번.
- 토글·프리셋은 **목표값을 콜백에 담기**(`m:t:cid:key:0|1`, `m:n:cid:key:val` + 허용값 화이트리스트 + `settings.coerce`) → 재전송해도 결과 동일.
- 삭제 등 파괴적 동작은 서버 쪽 1회용 확인 토큰(`m:ok:<tok>`, uid+cid+action 묶음, 120초).
- 편집 실패 대응: "not modified" 무시, "message to edit not found" 면 새 메시지. 미리보기는 새 메시지 + [🗑 닫기].
- 글자 입력 흐름: `svc.inputs[uid] = PendingInput(kind, cid, part, expires=5분)`, `menu.handle_input(svc, bot, msg)`.
  `.`/`/` 로 시작하면 통과, "취소"로 취소, 도착 시 권한 재확인. 한 사용자당 진행 중인 흐름 1개(예약공지 마법사와 상호 취소).
- `on_private` 순서: 딥링크·/start·/owner → 예약공지 마법사 → 메뉴 입력(미디어만 온 메시지도 여기까지 전달) → 명령어 → AI.
- 예약공지 마법사를 1:1 에서 쓰려면 `Draft.ui_chat_id`(대화가 오가는 곳)와 `chat_id`(공지 올릴 방) 분리.

## 태그 알림 (그룹헬프식)
- 그룹 메시지가 관리 검사를 통과한 뒤 백그라운드로: @username(방 멤버만) / text_mention 대상에게 1:1 알림
  "🔔 태그되었어요 · 보낸 사람 · 그룹 · 내용 200자 · [➡️ 메시지로 이동] [🔕 이 그룹 알림 끄기]".
- 대상 조건: 봇과 1:1 을 시작한 사람, 알림 끔 아님, **지금도 그 방 멤버**(get_chat_member, 10분 캐시).
- 제한: 메시지당 5명, 수신자별 같은 방 60초 1회·시간당 20회, 발신자 분당 10회. Forbidden 이면 dm_blocked.
- 새 설정 키 `tag_notify`(기본 True). 링크: 비공개 슈퍼그룹 `t.me/c/<-100 뗀 ID>/<msg_id>`, 공개 `t.me/<username>/<msg_id>`.

## 보안 체크리스트
콜백 위조(화이트리스트·범위) / 매번 권한 재확인 / 방 ID 로 범위 제한된 조회만(`get_schedule(cid,sid)` 등, 공통 자료는 방 관리자가 삭제 불가) /
재전송(목표값·1회 토큰) / 관리자 강등(on_chat_member 가 perms.forget) / 1:1 전용 강제 / 결제는 TG_ADMIN /
입력값 esc()·URL 버튼 https·tg:// 만·최대 6개 / 모든 변경 log_mod.

## 우선순위
- **P0**: 라우트 테이블·PanelCtx·_show 대응·목표값 토글·범용 프리셋·확인 토큰 / 허브·기능·입장(토글+캡차)·보안 화면(금지어·도메인 재사용: `db.banned_words`, `set_setting("whitelist_domains")`) /
  입력 엔진(`svc.inputs`, `menu.handle_input`) / on_private 순서 조정 / tests/test_menu.py 보강(64바이트, 위조 cid, 강등, 재전송, 입력 시간초과, 멤버에게 💳 안 보임).
- **P1**: 인사 편집기(설정 키 `greet_media_type/greet_media_id/greet_buttons`, Greeter 가 미디어·버튼 발송) / 예약공지 패널 + 마법사 1:1 분리 /
  AI 패널(말투·길이·사용량·자료) / 관리 기록 페이지 / 오너 메뉴(`payments_summary`, `unmatched_payments`, `all_subscriptions`) / 태그 알림.
- **P2**: chat_admins 캐시 테이블, 패널 1개만 살아있게, 규칙 편집, 답장 알림, 숫자 직접 입력, 봇관리자 관리, 오너 공통 자료 패널.
