# 소담 포인트 게임 설계

딜러 소담이 그룹에서 진행하는 포인트 게임. 명령은 전부 `!` 로 시작한다 (관리 명령 `.` 과 구분).

## 절대 규칙 (법·운영)
- 포인트(P)는 **가입·채굴·출석·파산 구제·게임**으로만 생긴다. **충전·환전·선물(이체) 없음** → 게임산업법 32조(환전 금지) 대응.
- 단위는 `P` (원·₩ 사용 금지). 포인트를 돈·코인·상품으로 바꿔주는 걸 봇 운영자·방 관리자 누구도 하면 안 된다.
- 다른 봇·사이트 이름을 문구에 넣지 않는다.
- 모든 게임의 기대 환급률(RTP)은 0.90~1.00 (오래 하면 조금씩 잃음 → 채굴·출석이 계속 의미 있음). 테스트가 시뮬레이션으로 검사.

## 흐름
```
!가입 (+10,000P, "이 방 N번째")  →  !채굴 10분마다 · !출석 하루 1번  →  게임  →  !순위 로 자랑
                                        ↑ 바닥나면 !파산 (하루 1번 +3,000P)
```

## 명령어 전체

### 시작 (가입 없이도 되는 것: !가입 · !순위 · !도움)
| 명령 | 별칭 | 설명 |
|---|---|---|
| `!가입` | join | 게임 가입, 10,000P 지급 |
| `!채굴` | mine, 캐기 | 10분마다 200~1,000P · 1/50 확률 💎 ×10 · 1시간 안 연속 채굴 +10%씩(최대 +100%) |
| `!출석` | daily | 하루 한 번 5,000P (한국시간 기준) |
| `!지갑` | 잔액, 돈, wallet | 잔액·방 순위·누적 베팅/당첨·채굴·출석 가능 여부 |
| `!순위` | 랭킹, 부자, rank | 방 포인트 부자 TOP 10 |
| `!파산` | 구제 | 잔액 100P 미만일 때 하루 한 번 3,000P |
| `!도움` | 게임, help, 명령어 | 게임 목록 |

### 주사위·슬롯 (텔레그램 애니메이션 — 결과는 텔레그램 서버가 정함)
| 명령 | 예 | 배당 (원금 포함) |
|---|---|---|
| `!홀짝` | `!홀짝 1000 홀` | ×1.95 |
| `!주사위` | `!주사위 1000 6` / `!주사위 1000 높음` | 숫자 ×5.7 · 높음(4~6)/낮음(1~3) ×1.95 |
| `!슬롯` | `!슬롯 1000` | 7️⃣7️⃣7️⃣ ×30 · 같은 그림 3개 ×10 |

|---|---|---|

| `!축구` | ⚽ | 골(3·4·5) ×1.37, 노골이면 42% 보너스 킥 (약 70%) |
| `!다트` | 🎯 | 정중앙 ×5.7 |
| `!볼링` | 🎳 | 스트라이크 ×5.7 |

| 명령 | 예 | 배당 |

| `!사다리` | `!사다리 1000 좌` | 좌·우 / 3줄·4줄 / 홀·짝 ×1.95 · 조합(좌3짝·좌4홀·우3홀·우4짝) ×3.8 |
| `!바카라` | `!바카라 1000 뱅` | 플레이어 ×2 · 뱅커 ×1.95 · 타이 ×10 · 플페어/뱅페어 ×13 (8덱, 정식 3번째 카드 규칙) |

| `!하이로우` | `!하이로우 1000` | 버튼 [하이][로우][그만] · 맞힐 때마다 배당 누적, 언제든 받기 |

### 방 전체가 같이 (멀티플레이)
| 명령 | 설명 |
|---|---|
| `!그래프 1000` / `!그래프 1000 2.5` | 15초 베팅 → 배당이 오르다 터짐. 살아 있는 차트(3초마다 갱신) 아래 **🛑 스톱 버튼**이나 `!스톱` 으로 그 순간 배당 받기, 숫자를 적으면 자동 스톱. 100배 도달 시 남은 사람은 100배로 자동 내림 |
| `!스톱` | 멈춰, stop — 그래프에서 받기 (버튼과 같음) |
| `!경마 1000 3` | 1~5번 말에 베팅, 20초 뒤 출발 · 맞히면 ×4.7 |
| `!라운드` | 지금 진행 중인 라운드 |

## 베팅 금액
`1000` · `5천` · `3만` · `1k` · `1,000` · `올인` · `반`(반띵) — 순서 자유 (`!홀짝 홀 1000` 도 됨).
최소 100P, 최대는 방 설정 `casino_max_bet` (기본 100,000P). 1인 2초에 한 번.

## 딜러 소담
결과마다 딜러 한마디 (AI 호출 없음, 비용 0). 방 말투가 자유분방이면 반말, 아니면 존댓말.
대박(×10 이상) · 승 · 본전 · 패 · 올인 패 별로 다른 대사.

## 안전장치 (코드)
- 잔액 변경은 `core.debit` / `core.credit` 만. 차감은 SQL 한 문장(`points >= ?`) → 동시 베팅에도 음수 불가.
- 모든 변동은 `casino_ledger` 에 기록 (테스트가 원장 합계 == 잔액 확인).
- 게임 명령은 도배·같은 말 반복 검사에서 제외 (대신 1인 2초 제한). 금지어·링크 검사는 그대로.
- 게임이 꺼진 방(`games_enabled`/`casino_enabled`)·이용 기간 끝난 방·1:1 에선 안 됨.

## 메인 봇 / 딜러 봇 나누기 (`BOT_ROLE`)
| 값 | 하는 일 |
|---|---|
| `all` (기본) | 한 봇이 관리·AI·게임 전부 |
| `main` | `!` 게임 명령만 무시 (나머지 전부) |
| `dealer` | 그룹의 `!` 명령만 처리하는 게임 전용 봇 |

두 봇을 같은 서버에서 **같은 `DB_PATH`** 로 켜면 포인트·방 설정·구독을 같이 쓴다.
실행: 메인 `python -m sodam` · 딜러 `SODAM_ENV=.env.dealer python -m sodam`
```
# 메인 봇 .env                     # 딜러 봇 .env.dealer
TELEGRAM_BOT_TOKEN=<소담 토큰>      TELEGRAM_BOT_TOKEN=<딜러 봇 토큰>
BOT_ROLE=main                       BOT_ROLE=dealer
DB_PATH=data/sodam.db               DB_PATH=data/sodam.db
```

## 공정성 (결과 봉인)
- 그래프·경마는 판을 열 때 결과가 정해진다. 여는 메시지에 `SHA-256(결과|열쇠)` 앞 16자리를 보여주고, 결과판에서 `결과|열쇠` 를 공개 → 누구나 해시를 계산해 중간에 안 바뀐 걸 확인.
- 주사위·슬롯·스포츠는 텔레그램 서버가 결과를 정함 (봇도 못 바꿈). ⚽ 는 4·5 만 골 (PTB 문서).

## 화면 연출 (메시지 하나를 고쳐 가며)
결과는 연출 전에 정해지고 **정산도 먼저 끝난다** → 화면 수정이 실패해도 돈·결과엔 영향 없음.

| 게임 | 연출 (보내기 1 + 수정) | 간격 |
|---|---|---|
| 🎡 룰렛 | 실제 휠 순서(0·32·15·19…) 5칸 띠가 흘러가다 느려지고 【결과】 칸에서 멈춤 · 🔴⚫🟢 · 수정 3 | ≈1.2초 |
| 🪜 사다리 | 출발만 보이고 ░ 로 가림 → 가로줄 2개까지 내려감 → 도착. 지나간 길은 굵은 선(┃━), 왼쪽 아래 홀·오른쪽 짝. 가림 높이는 같아서 3줄/4줄이 미리 안 샘 · 수정 2 | ≈1.2초 |
| 🃏 바카라 | **카드 그림 GIF**(아래) 1개 + 결과 캡션 1. 그림이 안 되면 글자: 🎴🎴 덮음 → 플레이어 2장 → (3번째 카드가 있으면) 뱅커 2장 → 결과, 점수 막대 `█████░░░░ 5` · 수정 2~3 | GIF 약 2.7~4초 / 글자 ≈1.2초 |
| 🃏 블랙잭 | **카드 그림 사진**(아래). 스탠드·더블·21 뒤 버튼 응답 먼저 → 딜러 숨긴 카드 공개(그림 교체 1) → 결과(교체 1). 글자 판은 중간 화면 최대 2 · 수정 2~3. 버스트·만료는 바로 결과 | ≈1.2초 |
| 🏇 경마 | 6프레임 · 순위 메달 🥇🥈🥉 · 선두·결승까지 남은 칸 · 결승 2칸 안 💨 · 우승 🏆 · 말별 베팅 인원 👥 | 3초(TICK) |

- 카드 모양(글자): `「A♠️」「10♥️」` (♥️♦️ 빨강 이모지). 하이로우는 단계 막대 🟩⬜.
- 간격 = `basic.anim_gap()` = `DICE_WAIT / 3` (한 판 연출 ≈ 주사위 애니메이션 3.5초). 테스트는 `basic.sleep` 을 바꿔 끼워 안 기다림.
- 중간 화면 수정 실패(429·BadRequest 등)는 건너뜀. 결과 화면은 429 면 기다렸다 한 번 더, 그래도 안 되면 **새 메시지로 결과**를 보냄.

## 화면 제한
- 그룹은 보내기·수정 합쳐 분당 약 20개 (텔레그램 FAQ) → 실시간 화면은 3초 간격, 🛑 버튼 응답은 누른 사람에게만(방에 메시지 안 늘어남).
- 한 판 연출은 보내기+수정 5개 이하 (룰렛·사다리·바카라 GIF 2 · 블랙잭 사진: 시작 1 + 버튼 한 번에 교체 1~2 · 하이로우 버튼마다 교체 1).
- 마지막 화면·결과판은 429 에 걸리면 기다렸다 한 번 더 보냄.

## 🂡 카드 그림 (`casino/cardimg.py`, Pillow)
- 흰 둥근 카드 · 모서리 숫자+작은 무늬 · 가운데 큰 무늬 (J·Q·K 는 금색 테두리+큰 글자). ♥♦ 빨강 · ♠♣ 검정.
  무늬는 폰트 글리프 대신 **도형(다각형·원)으로 직접** 그림 (서버 폰트에 ♠♥♦♣ 가 없어도 됨). 숫자·영문은 DejaVu Bold, 없으면 기본 폰트.
- 초록 펠트 테이블: 줄마다 이름(PLAYER/BANKER · DEALER/YOU) · 카드 · 점수 동그라미, 이긴 줄 금색 테두리, 아래 결과 띠(영문).
  이미지 안엔 한글 없음 → 한글 설명은 캡션.
- 🃏 바카라: 빈 테이블 → P1 B1 P2 B2 (P3) (B3) 가 **뒷면 → 앞면**으로 한 장씩 놓이는 GIF (같은 화면은 프레임 길이로 늘려 인코딩 약 0.3초) → 결과 강조.
  보내기 = `basic.show_anim` (GIF 1 + 끝나면 캡션 결과 수정 1). 캡션엔 카드 글자를 빼고 승자·점수만.
- 🃏 블랙잭 · 🔼🔽 하이로우: 시작 = `send_photo`(테이블 사진 + 캡션 + 버튼), 버튼마다 `edit_message_media`(새 사진+캡션, 버튼)로 교체.
  딜러 숨긴 카드는 뒷면 그림. 한 장 그리기 약 0.05초 · PNG 20~30KB. 하이로우 = 지난 카드(작게) · 지금 카드(크게) · HI/LO 배수 · 단계 칸.
- 실패하면 자동으로 글자: 그리기·사진 보내기 실패 → 옛 글자 메시지 · 판 도중 그림 교체 실패 → 캡션을 카드 글자 화면으로 고침(버튼 유지).
  정산은 그림과 무관하게 먼저 끝남 (테스트가 같은 카드로 그림 판/글자 판 원장이 같은지 확인).
- `cards.IMAGES = False` 면 전부 글자 화면 (옛 테스트가 글자 형식을 검사할 때 씀).

## 🧹 방에 메시지 안 쌓이게
- 그래프·경마 **🎫 참가 확인**은 베팅 마감 무렵(남은 초 + 3초) 자동 삭제. '이미 걸었어요'·'이미 출발'·'꽉 찼어요'·그래프 '출발 전' 같은 안내는 20초 뒤 삭제
  (`core.temp_reply` / `core.delete_later`: job_queue 없이 asyncio 태스크, 봇이 꺼지면 그냥 남음). 판 여는 메시지·결과판·스톱 결과는 남김.
- **게임이 꺼진 방·이용 기간 아닌 방**의 `!` 명령 안내는 **방당 10분에 1번**. 그 사이 명령은 답장 없이 명령 메시지만 지우기 시도(`core.GATE_QUIET`).
  룰렛 버튼판은 누른 사람 알림창으로만 알려서 횟수에 안 셈.
- 📈 그래프 진행판(살아 있는 차트)은 끝나면 `💥 N.NNx에서 터졌어요!` + 전체 차트로 바뀌고 🛑 버튼이 사라짐. 결과판(누가 얼마)은 새 메시지 1개.
- 주사위류 결과: `🎲 주사위 ⚂ 3 → 홀 · 홀 선택 ✅ 적중!` · `🎰 [ 7️⃣ | 7️⃣ | 7️⃣ ] ✅ 같은 그림 3개! ×30` · `🏀 농구 성공! ✅`.

## 🖼 그림장 (`!그림장 [바카라|홀짝|룰렛|사다리|그래프|경마]`, 별칭 출목·road)
- 방의 최근 결과를 **이미지 한 장**으로 (Pillow). 기본 바카라 = 위 본매(한 판씩) + 아래 연속 줄(같은 쪽이면 아래로, 6칸 넘으면 옆으로 꼬리, 타이는 초록 빗금, 페어는 점).
- 그래프는 최근 40판 막대(2배 이상 초록), 나머지는 결과 격자. 캡션에 한글 통계.
- 이미지 안엔 기호·숫자·영문만 (서버마다 한글 폰트가 달라 깨짐 방지). 방마다 10초에 한 번. 결과는 방·게임마다 최근 120판만 보관(casino_results).

## 결과 애니메이션 · 버튼 베팅판
- 룰렛(공이 휠을 돌다 결과 칸에 멈춤) · 사다리(길 따라 내려감) · 경마(말이 달림)는 **결과를 정하고 정산한 뒤** 그 결과로 끝나는 GIF 를 서버가 그려 보낸다(anim.py, 약 1초).
  한 판 = 애니메이션 1개 + 다 돈 뒤 결과 캡션 수정 1번. 그리기·보내기가 안 되면 글자 연출로.
- 그래프는 애니메이션 없음: 미리 그린 영상엔 터지는 지점이 들어 있어 판 도중에 보내면 결과가 샘 → 실시간 차트 + 🛑 버튼.
- `!룰렛` / `!룰렛 1만` 처럼 칸을 안 적으면 **버튼 베팅판**: 금액 칩(1천·5천·1만·5만) 고르고 빨강·검정·홀·짝·1~18·19~36·숫자 칸을 누르면 바로 돈다. 판 연 사람만 누를 수 있고, 입장 검사(가입·꺼진 방·이용 기간)는 명령과 같음.
