# 🧠 소담을 '클로드급 에이전트'로 — 격차 분석 + 로드맵

작성 2026-11-27. 근거: ① 소담 코드 정밀 매핑(agent.py·tools.py·prompt.py·llm.py·route.py·memory.py·whyfail.py·aiqueue.py, file:line) ② 앤트로픽 공식 문서 20개(how-claude-code-works·sub-agents·skills·hooks·context-window·tool-search·prompt-caching·building-effective-agents·effective-context-engineering·long-running-agents 등).

> **한 줄 결론:** 소담은 "단톡방에서 25초 안에 답하는 **얕은 단일 에이전트**"로 **의도적으로** 설계됐다. 클로드 코드(수십~수백 툴콜을 도는 심층 코딩 에이전트)를 그대로 베끼면 오히려 느려지고 망가진다. 진짜 격차를 메우는 열쇠는 **"깊은 작업만 백그라운드 트랙으로 빼는 것"** — 소담은 이미 그 배관(persist.spawn·'만드는 중…'·예약·aiqueue)을 갖고 있어 **프레임워크 하나로 묶으면** 된다.

## 3. 뭘 해야 하고 뭘 하면 안 되나 (소담 현실 반영)

소담은 클로드 코드(코딩 IDE 에이전트)가 아니라 **텔레그램 운영 에이전트**다. "텔레그램 No.1"은 클로드 코드 복제가 아니라 **운영 작업을 더 깊고·정확하고·안 막히게** 하는 것이다. 25초 채팅 루프를 깨면 안 된다.

### ❌ 하면 안 되는 것 (제약 존중)
- **인라인 채팅 경로에 깊은 100툴콜 루프 넣기** — 25초 약속이 깨진다. 깊은 작업은 ↓ 백그라운드 트랙으로.
- **범용 파일시스템·셸** — 의도적으로 뺐다(보안). 운영 도구로 특화 유지.
- **추론을 모델 완전자율로** — 비용 폭발. 코드 게이트 유지하되 ↓ '더 생각' 탈출구만.

## 4. 로드맵 (소담 확장규칙 = `panels/<이름>.py` + `register_*`, 부품+값 철학)

### 🥇 Tier 1 — 가장 큰 열쇠

**① 백그라운드 '깊은 작업' 트랙 (deep-task) — 서브에이전트·깊은루프·계획을 한 번에 메움**
- **문제:** 25초·8라운드 캡 때문에 "여러 방에 공지 정리해서 뿌려줘", "이 자료 분석해서 규칙 만들어", "최근 사기 패턴 조사해서 보고" 같은 **진짜 다단계 작업**을 못 한다 → "지금까지로 마무리"하고 끊김.
- **해법:** 요청이 깊은 작업이면(코드 판정: 다단계·조사·여러 방·보고서) 인라인에서 즉답 대신 **`persist.spawn`으로 백그라운드 에이전트 실행**(캡 없음·툴 다 있음), 방엔 "⏳ 정리하는 중…" 답장(ctx.quiet), 끝나면 결과 배달 + 진행 중 업데이트. **클로드의 서브에이전트+async가 바로 이것**이고, 소담은 이미 배관을 다 갖고 있다: 스티커 `copy_sticker`·영상 `make_video`가 정확히 이렇게 돈다(`persist.spawn`, 사람당 1개 RUNNING, "만드는 중" → 배달).
- **프레임워크로:** `TERMINAL` 도구 개념을 일반화 → `deep_task(goal, deliver=room|dm)` 메타도구. 캡 = 별도(DEEP_STEPS·DEEP_USD), 결과는 **요약 1~2k로 방에**(클로드 서브에이전트 반환 규격). 격리(tainted 전파)·동시 1개·예산은 기존 가드 재사용.
- **효과:** 서브에이전트(#2)·깊은 다단계(#5)·계획(일부)을 **동시에** 메운다. 25초 약속은 그대로.
- 근거: sub-agents(격리·요약반환), long-running-agents(완료정의·진행파일·상한·사람승인), 소담 `aiqueue`·`persist.spawn`·`agent.TERMINAL`.

**② 계획 카드 (조각3, 이미 로드맵)**
- 되돌리기 어려운 **여러 단계**(예: "밴+공동차단+공지+뮤트")는 **한 장에 전체 계획 → 1회 승인 → 순서대로 실행**. 클로드 plan-mode의 확인카드판.
- 소담 `menu.lasting_token` 확인카드 관용구에 그대로 얹힘. CLAUDE.md "조각3 아직 — 다음 작업"과 일치.
- 근거: permission-modes(plan mode), 소담 확인카드.

### 🥈 Tier 2 — 신뢰·정확도 (싸고 효과 큼)

**③ 답에 '영수증' 붙이기 (검증 가시화)**
- "뮤트했어/등록했어" 할 때 **실제 증거**(대상·시각·건수·msg id)를 한 줄 붙인다. 클로드의 "show the output" 습관 = 가장 싼 신뢰 획득.
- 인프라 이미 있음: `evidence.py`(receipts)·`show_evidence`·`moderation._ensure`(제재 후 read-back). 제재·등록·예약 결과에 코드가 영수증 한 줄 덧붙이게.
- 근거: best-practices("All tests pass는 아무것도 말해주지 않는다"), 소담 `evidence.receipts`·`moderation._ensure`.

**④ 능동적 실패 복구 (retry_hint 업그레이드)**
- 지금: 부드러운 실패 → 힌트 문장만 붙이고 **모델 재량**(`tools.py:1715`). → "못 찾음"이면 **코드가** 뻔한 대안 1회 자동 시도(다른 인자/도구) 후에만 포기. "못 해요" 빈도↓.
- 루프 가드 1회(무한방지)는 기존 `_CLAIM` 패턴 재사용.
- 근거: building-effective-agents(poka-yoke·actionable errors), 소담 `retry_hint`·`refuse` 검사.

**⑤ 도구결과 '유도 메시지' (기계적 자르기 → 안내)**
- 결과가 잘리면 `clip_mid` 무음 자르기 대신 **"결과가 많아 잘렸어 — 낱말 좁혀 다시 불러"** 를 붙여 모델을 다음 행동으로 유도. 클로드 도구결과 규격.
- 근거: writing-tools-for-agents(pagination·actionable), 소담 `agent.TOOL_RESULT_CHARS`.

### 🥉 Tier 3 — 장기·선택

**⑥ 작업-범위 상태(task-scoped state)** — `recent_actions` 30분·3개는 짧다. 진행 중인 작업(공지 마법사·조사 스레드)은 **작업 단위 상태 blob**을 다음 턴이 읽게(클로드의 progress file). 긴 연속작업 연결.
**⑦ '더 생각' 탈출구** — 추론은 코드 게이트 유지(비용)하되, 어려운 문제에서 모델이 `think_more` 도구로 **스스로 한 단계 더** 요청 가능하게(자율성 조금, 비용 캡 안). thinking-tool-workflows(위험도별 effort).
**⑧ 종료조건 가시화** — 상한/예산에 걸려 끊길 때 "여기까지 했고 ○○가 남았어(상한)" 로 **뚜렷이**. how-claude-code-works(distinct stop reasons).

## 5. 요약 — 격차의 정체

소담이 클로드급과 벌어진 **5대 격차(계획·서브에이전트·깊은루프·긴컨텍스트·반복자기수정)는 전부 "단톡방 25초" 제약에서 의도적으로 빠진 것**이다. 그대로 베끼면 안 된다.

**가장 큰 한 수 = ①(백그라운드 deep-task 트랙).** 이 하나가 서브에이전트+깊은루프+계획을 25초 약속을 깨지 않고 동시에 메운다. 그리고 소담은 이미 배관(persist.spawn·"만드는 중"·aiqueue·TERMINAL)을 갖고 있어 **새 프레임워크 하나로 묶는 작업**이지 바닥부터가 아니다.

그 위에 ③영수증·④능동복구·⑤유도메시지 세 개(싸고 효과 큼)를 얹으면, 소담은 "빠른 반응"은 그대로 둔 채 **깊은 작업·정직한 검증**까지 하는 — 텔레그램에서 보기 드문 운영 에이전트가 된다.

> 소담은 이미 인젝션 방어·비용 라우팅·재시작 복원에서 클로드보다 앞서 있다. 격차는 '깊이', 강점은 '안전·운영'. **깊이를 백그라운드로 더하면 둘 다 갖는다.**
