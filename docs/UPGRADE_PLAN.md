## 빌드 순서 (한 번에 하나)
0. ✅ 🛡 수배(박제) 조회 시스템 — 완료 (PR #217). 원글 저장·누구나 조회·공개 카드·warn/ban 모드.
1. 💱 **실시간 시세 (rates.py)** — 독립 모듈. 업비트 KRW-USDT(주)→빗썸(폴백)→코인게코. 30~60s 전역 캐시, 800~2500 sanity, 지어내기 금지. 입력 `50테더/100만원/.시세` 양방향, 만/억 파싱, 키워드+숫자일 때만(오탐 차단). AI 도구 rate_convert. 방 설정 rate_enabled **기본 off**. "참고용" 표기(업비트 약관 회색지대). 안티패턴 회피(verify=False·토큰하드코딩·Origin헤더 금지).
2. 🎨 **전 버튼 색(스타일)** — Bot API 9.4 style(""/primary/success/danger). menu 버튼 생성 공통부 1곳에서 콜백접두어·글자로 자동 매핑(🟢실행·결제 / 🔵조회·메뉴 / 🔴밴·삭제·취소 / ⚪뒤로). 채널/방 글(composer)은 방장이 **틀(테마)만 선택**(파랑심플/신호등/무채색/강조). PTB 가 style 싣는 실제 방법 먼저 실측. (brand.py STYLES 재사용)
3. 🏷 **빼고 태그 + 반복 태그** — mention_members 에 exclude 인자, alert_rule/schedule_task 가 N분마다 반복 태그. 프레임워크(값 조합), AI 0.
4. 🤝 **제휴 CRM** — partners·ad_campaigns·ad_slots·referral_links·referral_events·billing. 제휴별 1회용 초대링크(createChatInviteLink)+chat_member 로 유입 집계(소급 불가). 🏅 검증 업체 마크/명함 카드(유료 뱃지 가능). 광고 문구만 AI 선택. 기본 off.
5. 🚨 **신고 접수 센터** — 접수번호→검토→조치→종료→이의제기, 신고자/운영진 권한 분리. 수배랑 짝. AI 0. 기본 off.
6. 📡 **통합 공지(브로드캐스트)** — 오너 승인 방에만, 방별 성공/실패 기록. AI 0.
7. 📈 **네트워크 분석 + 주간 보고서** — reports 재활용 코드 집계. **⚠️ 보고서에 AI 모델 쓰지 말 것(오너 결정) = 전부 코드·템플릿 문장, LLM 0.**
8. 🏅 활동 레벨·배지 — 코드/DB. 기본 off. 기반 안정화 뒤.
9. ❤️ 유지 기능 (오너가 톱3 찍은 것부터): 🌅 대표님 아침 브리핑(코드 집계) · 💔 이탈 레이더 · 🛡 계정 신뢰 점수(수배와 짝). 기본 off.
10. ⚙️ **소담 병렬/백그라운드 실행 확장** (오너 요청): 지금 READ_ONLY 조회만 parallel_tool_calls 동시 → 독립 쓰기/제작(그림 여러 장·독립 작업)도 안전하면 동시 실행 + 긴 작업은 persist.spawn 백그라운드로 돌리고 응답은 계속(이미 영상·스티커·음악은 함 → 일반화). 동시성 버그 위험 커서 신중·시험 많이. Codex parallel.rs 참고.
