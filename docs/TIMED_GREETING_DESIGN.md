# 🌅 시간대 인사 — 아침·점심·저녁 멘트 돌리기 (설계)

## 요청 (오너 2026-11-12)
아침·점심·저녁 자동 인사 멘트를 **AI 티 없이** 넣고, 수정은 **버튼 마법사**로, **시간대(시각)도 설정 가능**하게.
"어케하는 게 좋은지 사례 검색하고 클로드가 선택해서 설계."

## 사례 조사 (무엇이 표준인가)
- **멘트 풀 + 무반복 로테이션이 업계 표준.** 시간대 슬롯(아침/점심/저녁)마다 메시지 리스트를 두고 그 안에서
  돌아가며 하나 (Botize '목록에서 메시지 골라 보내기', cron 봇들).
- **AI 매번 생성은 피하는 쪽.** 연구용 소셜봇 Gunrock조차 '반복·엉뚱함'을 피하려고 **손으로 쓴 템플릿 풀**을 씀.
  AI 생성은 품질이 들쭉날쭉하고 가끔 어색·엉뚱, 비용도 듦.
- **변주(spintax)**: `{좋은 아침 | 굿모닝 | 아침이다}` 식으로 같은 뜻 여러 표현 — 반복 티를 더 줄임.
- **간격(spacing)·빈도**: 같은 멘트 재사용 전 최소 간격, 하루 자동 멘트는 적게. 너무 많으면 멤버 피로·이탈.
- **타임존은 오디언스(방 손님) 기준** — 소담은 이미 한국 시각(KST) 기준이라 OK.
- 반복되면 문구를 주기적으로 갱신 (관리자가 멘트 풀 손봄).

출처: Botize formula 279/899, Gunrock(arXiv 1910.03042), Reply.io spintax, Ada greeting best practices, Pedowitz(로봇 느낌 피하기), metricgram(텔레그램 자동화).

## 결정 (Claude 선택) — 오너 피드백 반영
**예약공지는 '제휴 공지' 전용 자리라 인사멘트와 섞으면 안 됨** (오너). → 예약공지 확장이 아니라
**별도 '🌅 인사멘트' 전용 버튼/기능**으로 분리. 단 발송 엔진(schedules·cron·무반복 순환)은 재사용.

핵심 = **"AI 티 없이" = 애초에 AI를 안 쓰고 방장이 쓴 멘트 풀을 무반복으로 돌린다.** 티 0·비용 0.
겨울 느낌도 사람이 멘트에 넣으면 됨. (AI 변주는 선택 토글로만, 기본 꺼짐.)

1. **별도 기능 '시간대 인사'** — 그룹 허브에 **🌅 인사멘트** 버튼(예약공지 🗓 옆). 목록도 따로라 제휴 공지와 안 섞임.
2. **전용 간단 마법사** (예약공지보다 단순 — 제목·유효기간 없음):
   ① 시간대 고르기(🌅 아침·🌞 점심·🌙 저녁 프리셋 시각, 또는 직접 HH:MM)
   ② **멘트 여러 개 쌓기** (방금 PR#304 버튼 쌓기 UX 그대로 — 한 줄/한 메시지씩 추가, ✅ 이대로)
   ③ 요일(매일/평일/주말)
   ④ 저장 (미리보기 → 저장)
3. **무반복 로테이션** — 그 시각마다 아직 안 쓴 멘트부터, 다 돌면 다시 섞어서. 같은 멘트 연속 X.
4. (선택·2단계) **AI 변주 토글** — 뽑은 멘트를 AI가 살짝만 다듬음. 기본 꺼짐.

## 구현 설계
- **DB 재사용**: `schedules` 테이블에 `category` 칸 추가 (`'announce'`=예약공지 / `'greet'`=인사멘트).
  멘트 풀은 `variants` 칸(JSON 리스트). 예약공지 목록은 category='announce'만, 인사멘트 허브는 'greet'만.
- **발송(`publish`/cron)**: 같은 엔진 재사용. `variants` 있으면 커서(`variant_cursor` 1칸)로 다음 멘트 골라
  무반복 순환. 인사멘트는 del_prev 기본 끔(쌓임 — 인사는 지우면 어색), 제목 없음.
- **전용 마법사**: `panels/greetmsg.py` 새 파일 (announce 마법사 참고하되 단순화). 허브 🌅 버튼·목록·수정.
- **분리 이점**: 예약공지(제휴)는 손 안 대고 그대로, 인사멘트는 자기 자리에서만.

## 안 하는 것 (사례·오너 철학 반영)
- **AI 매번 생성 기본값 X** — 티·비용·엉뚱함. 토글로만.
- 하루 자동 멘트 과다 X — 아침·점심·저녁 3번이 적정 (사례: 많으면 피로·이탈).
- 멘트 풀에 링크·지갑주소 (기존 공지 필터 그대로).

## 단계
- **1단계**: `variants` 칸 + 마법사 멘트 쌓기 + publish 무반복 순환 + 테스트/뮤테이션.
- **2단계**: "아침·점심·저녁 한 번에" 생성 헬퍼.
- **3단계(선택)**: AI 변주 토글.
