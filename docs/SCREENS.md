# 소담 버튼 메뉴 화면 모음 (자동 생성)

`python tools/render_screens.py` 로 다시 만든다. 하네스가 실제로 버튼을 눌러서 나온 화면 그대로다.

- 누른 버튼 수: 316
- 발견된 문제: 0

## 오너 로 본 화면

### `m:home`
```
👋 안녕하세요, 소통방 AI 비서 **소담이에요**

**이런 걸 해드려요**
• 🛡️ 방 관리: 입장 캡차, 도배·링크·사칭 차단, 경고·뮤트
• 🤖 AI 비서: 질문 답변, 방 자료 학습, 인사, 요약
• 🎮 게임·🗓️ 예약공지·📊 채팅 랭킹·통계

**시작하는 방법 (방 관리자)**
1️⃣ 아래 **➕ 내 그룹에 추가하기** → 방 선택 (필요한 관리자 권한이 자동으로 체크돼요)
2️⃣ 방에서 봇이 **관리자**인지 확인
3️⃣ **⚙️ 내 그룹 관리** 또는 방에서 `.설정` → 버튼으로 기능 설정

방에서는 `소담아 …` 로 부르면 돼요. 여기(1:1)서는 그냥 말을 걸면 AI와 대화할 수 있어요.
──────────────────────────────
[➕ 내 그룹에 소담 추가하기]
[⚙️ 내 그룹 관리]
[🪪 내 ID]  [❓ 도움말]
```
