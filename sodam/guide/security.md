## 한 줄 답
방 관리 기능은 **무료**예요. 소담을 관리자로 올리고 '메시지 삭제'·'사용자 차단' 권한을 주면 캡차·도배·링크·사칭 차단이 바로 동작해요.

## 자동으로 막는 것 (기본값)
| 기능 | 기본 |
|---|---|
| 입장 캡차 | 켜짐, 5분 안에 그림 버튼, 실패하면 내보냄 |
| 스팸 명단 계정 차단 | 켜짐 |
| 관리자 사칭 이름 | 켜짐 |
| 도배 | 8초에 6개 → 30분 채팅 금지 |
| 같은 말 반복 | 3번 → 삭제 + 경고 |
| 링크 | 관리자 외 링크 삭제, 새로 온 사람은 24시간 링크 금지 |
| 대량 입장 | 60초에 10명 → 방어 모드 |
| 봇 조종 시도 | 거절 + 경고 |

바꾸는 곳: 설정 [🚪 입장·인사] · [🛡️ 보안] · [🔒 종류별 잠금] · [🚨 대량 입장 방어].

## 경고·제재 명령 (관리자)
- `.경고 @user 사유` → 3번이면 1시간 채팅 금지, 5번이면 밴 (단계는 [⚠️ 경고 단계]에서).
- `.뮤트 @user 2h` · `.밴 @user`(영구 추방) · `.킥`(내보내기, 다시 들어올 수 있음) · `.밴해제` · `.잠금` · `.청소 개수`.
- `.금지어 추가 단어` · `.허용도메인 추가 도메인` · `.free @user`(자동 통제 제외).

## 말로도 돼요 (관리자)
- 제재·풀기 → 방에 확인 카드, 눌러야 실행: "소담아 철수 1시간 뮤트해" · "영희 내보내"(킥) · "스팸계정 밴해"(영구) ·
  "@abc 밴 풀어줘"(방에 없어도 ID·@) · "철수 경고 하나 취소" · "영희 경고 초기화" · "민수 자유 멤버로" · "신입 캡차 통과시켜".
- 방 잠가줘 · 최근 20개 지워줘 · "내일 정모 7시 공지 올리고 고정해" → 확인 카드.
- 바로 바뀜: "유튜브 링크 허용해줘"(기존 허용 도메인은 그대로) · "금지어에 먹튀 추가해" · "사진 막아줘" · "사기 의심 검사 켜줘".

## 패드립·성적 모욕 자동 제재 (선택, 기본 꺼짐)
[🤬 패드립·성적 모욕]: 남의 부모 욕·사람을 향한 성적 모욕만 AI 확인 뒤 1분 → 3분 → 밴(바꿀 수 있음), 24시간 지나면 초기화. 감탄 욕·장난·소담에게 한 말은 안 잡아요. 👀 기록만으로 먼저 오탐을 보고, 추방되면 관리자 1:1 에 [↩️ 되돌리기].

## 조건·예외
- 제재는 텔레그램 '사용자 차단' 권한이 있는 관리자만. 관리자·봇은 제재할 수 없다.
- AI 가 하는 제재는 **항상 확인 카드**를 거친다.
- 이용 기간에만: 사기 의심 검사, 스팸 방패(AI), 공동 차단 올리기.
