## 한 줄 답
"**.노래 제목**"(또는 유튜브 링크)을 보내면 소담 노래 도우미가 음성채팅에 들어와 노래를 틀어요. "소담아 아이유 밤편지 틀어줘"라고 말해도 돼요.

## 하는 법
| 하고 싶은 것 | 명령 |
|---|---|
| 노래 틀기·대기열 추가 | `.노래 제목` · `.노래 유튜브링크` · 음악 파일에 답장하며 `.노래` |
| 다음 곡 | `.스킵` |
| 멈춤·다시 | `.일시정지` · `.다시재생` |
| 대기열 보기·빼기 | `.대기열` · `.빼기 번호` |
| 위치 이동 | `.이동 90` · `.이동 +30` · `.이동 1:30` |
| 음량·반복 | `.볼륨 50`(0~200) · `.반복 2` |
| 노래 소리만 끄기·켜기 | `.음소거` · `.음소거해제` |
| 끝내기 | `.노래끝` (음성채팅에서 나감) |
- 영어 명령(`/play` `/skip` `/pause` `/resume` `/queue` `/remove` `/seek` `/volume` `/end`)도 같아요. 명령 메뉴에서 고르면 소담 것으로 보내져요.
- 재생 카드의 [⏸ 일시정지] [⏭ 다음] [⏹ 끝내기] 버튼으로도 돼요.
- 소담 음성 대화 중이면 소담이 말할 때 노래 소리가 잠깐 작아져요.

## 방 설정 (관리자, [🎵 뮤직봇])
- 노래 신청: 누구나(기본) / 관리자만.
- 넘기기·멈춤: 관리자·그 곡 신청자(기본) / 누구나.
- @ 없는 `/play` 받기: 기본 꺼짐 (다른 음악 봇이 있는 방에서 둘 다 틀지 않게).

## 조건·예외
- 이용 기간 중인 방만. 노래 도우미 계정이 방에 있어야 하고, 음성채팅이 꺼져 있으면 '음성채팅 관리' 권한으로 직접 켜요.
- 대기열은 방마다 30곡, 한 사람 5곡까지. 20분 넘는 영상·라이브 방송은 안 돼요.
- 3분 동안 틀 노래가 없으면 음성채팅에서 나가요. 서버 업데이트로 잠깐 끊겨도 이어서 틀어요.
- 유튜브에서 못 받을 때는 SoundCloud 에서 같은 노래를 찾아 틀어요 (재생 카드에 SoundCloud 표시). 같은 노래가 없으면 "못 찾았어요".
- `/mute` 는 멤버 뮤트예요. 노래 소리는 `.음소거`.

## 소담이 하지 말 것
- 노래가 나오는지 확인 안 하고 "틀었어요"라고 하지 않기 (결과는 재생 카드가 알려 줌).
- 유튜브·SoundCloud·음악 파일 말고 다른 음원 서비스가 된다고 하지 않기.
