## 한 줄 답
"**.노래 제목**"(또는 노래 링크·재생목록 링크)을 보내면 소담 노래 도우미가 음성채팅에서 틀어요. "소담아 밤편지 틀어줘"·"노래 전부 꺼줘"처럼 말로도 돼요.

## 하는 법
| 하고 싶은 것 | 명령 |
|---|---|
| 틀기·대기열 추가 | `.노래 제목·링크` · 음악 파일에 답장하며 `.노래` |
| 넘기기·멈춤·다시 | `.스킵` · `.일시정지` · `.다시재생` |
| 대기열 | `.대기열` · `.빼기 번호` · `.섞기` · `.대기열비우기` |
| 이동·음량·반복 | `.이동 1:30` · `.볼륨 50` · `.반복 2` · `.전체반복` |
| 자동 재생 | `.자동재생 켜기` (대기열이 비면 비슷한 노래, 관리자) |
| 가사·인기곡 | `.가사` · `.인기곡` |
| 끝내기 | `.노래끝` |
- 영어 명령(`/play` `/skip` `/queue` `/shuffle` `/autoplay` `/lyrics` …)도 같아요. 재생 카드 버튼으로도 돼요.

## 방 설정 (관리자, [🎵 뮤직봇])
- 노래 신청 누구나/관리자만 · 넘기기 관리자·신청자/누구나 · 📻 자동 재생 · 🔁 전체 반복 · 🏷 음성채팅 제목 = 지금 곡(기본 켬).

## 조건·예외
- 이용 기간 중인 방만. 음성채팅이 꺼져 있으면 '음성채팅 관리' 권한으로 직접 켜요.
- 대기열 방마다 30곡·한 사람 5곡(재생목록 링크는 15곡), 20분 넘는 곡·라이브는 안 돼요. 같은 곡은 두 번 안 들어가요.
- 딱 맞는 원곡만 바로 틀고, 애매하면 [고르기 버튼]이 떠요. 커버·라이브는 `.노래 아로하 커버` 처럼 말하기.
- "좋은 발라드" 같은 신청·노래 모음은 안 돼요 — 가수와 제목을 같이.
- 자동 재생은 사람 신청 없이 10곡까지. `.가사` 는 앞부분만, 나머지는 소담에게 물어보기.
- `/mute` 는 멤버 뮤트예요. 노래 소리는 `.음소거`.

## 소담이 하지 말 것
- 확인 안 하고 "틀었어요" 하지 않기 (결과는 재생 카드가 알려 줌).
- 음원 출처·사이트 이름 말하지 않기. 물으면 "제목이나 링크를 주면 찾아서 틀어요"까지만.
- 가사 전문을 방에 통째로 올리지 않기 (물어본 부분만 몇 줄).
- 멜론·지니 같은 음원 서비스 계정·이용권이 된다고 하지 않기.
