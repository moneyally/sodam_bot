## 한 줄 답
보여 줄 글에 **답장**으로 `.reply 공지` 라고 치면, 그다음부터 누가 **공지** 라고만 쳐도 소담이 그 글을 그대로 답장으로 올려요.

## 하는 법
| 하고 싶은 것 | 방법 |
|---|---|
| 만들기 | 보여 줄 글(사진·영상·GIF·스티커·음성·파일 다 돼요)에 답장하며 `.reply 낱말` |
| 글을 바로 쓰기 | `.reply 입금 입금은 관리자 1:1 로 문의해 주세요` |
| 여러 낱말 한 번에 | `.reply 공지, 공지사항` (답장하면서) |
| 지우기 | `.reply 취소 낱말` · `.답글취소 낱말` · `.unreply 낱말` |
| 목록 | `.reply 목록` |
| 말로 | "소담아 공지 치면 이거 나오게 해줘" (글에 답장하면서) · "공지 자동 답글 지워줘" |
| 버튼으로 | 소담 1:1 → 방 고르기 → [💬 자동 답글 (낱말 → 글)] → [➕ 새 자동 답글] → 낱말 보내기 → 보여 줄 글 보내기 |
- `.답글` · `.리플` · `.자동답글` 도 `.reply` 와 같아요.

## 조건·예외
- 관리자만 만들고 지울 수 있어요. 누르는(치는) 건 누구나.
- 글 전체가 그 낱말일 때만 나와요 ("공지 언제 올라와요?" 처럼 문장 속에 있으면 안 나옴). 띄어쓰기·대소문자·끝의 ?! 는 상관없어요.
- 같은 낱말은 30초에 한 번만 (버튼 화면에서 10초~5분으로 바꿔요), 한 사람은 1분에 5번까지 (다른 낱말은 바로바로) — 도배 막기.
- 방마다 50개까지. 소담 명령어(`.공지` 같은 것)와 같은 낱말은 못 써요.
- 원본 글을 지워도 소담이 따로 저장해 둔 사본으로 계속 나와요.

## 소담이 하지 말 것
- 글에 답장 안 하고 "만들어 줘" 하면 지어내지 말고, 보여 줄 글에 답장하면서 다시 말해 달라고 하기.
- 관리자가 아닌 사람에게 만들어 주지 않기.
