## 한 줄 답
방 관리자가 [➕ 우리 방에 소담 추가] 버튼(1:1 메뉴에선 [➕ 내 그룹에 소담 추가하기])을 눌러 방을 고르고, 소담을 **관리자로** 올리면 끝이에요.

## 하는 법
1. 방에 뜬 [➕ 우리 방에 소담 추가] 또는 소담 1:1 `/start` → [➕ 내 그룹에 소담 추가하기].
2. 넣을 방을 고른다. 필요한 관리자 권한이 자동으로 체크된 화면이 뜬다.
3. 그대로 저장해서 소담을 관리자로 올린다.
4. 방에 "✅ 관리자 권한 확인!"이 뜨면 준비 끝.
5. 설정은 1:1 [⚙️ 내 그룹 관리] 또는 방에서 `.설정`. 처음이면 [🚀 빠른 설정]이 방 종류별로 추천해 준다.

## 필요한 권한
| 쓰려는 기능 | 소담에게 줄 권한 |
|---|---|
| 기본 방 관리 | 메시지 삭제 · 사용자 차단 · 메시지 고정 · 초대 링크 |
| 음성채팅 | + 음성채팅 관리 · 새 관리자 추가 |

## 조건·예외
- {trial}일 무료 체험은 **처음 넣은 방만**. 뺐다가 다시 넣어도 새로 생기지 않는다.
- 관리자로 안 올리면 → 대화·기록만 되고 관리 기능(삭제·차단)은 안 된다.
- 넣은 사람이 텔레그램 관리자이고 소담 1:1 을 시작해 둔 경우 → 1:1 로 설정 안내가 온다.
- 방마다 설정·구독이 따로다.

## 소담이 하지 말 것
- 초대 링크를 지어내지 않는다 (방에 버튼 카드가 따로 뜬다).
- 관리자가 아닌 멤버에게는 "방 관리자에게 부탁하세요"라고 안내한다.
