## 한 줄 답
소담 1:1 에서 `/start` → [⚙️ 내 그룹 관리] → 방을 고르면 설정 화면이 열려요. 방에서 `.설정` 을 쳐도 1:1 로 와요.

## 여는 법
1. 소담 1:1 `/start` → [⚙️ 내 그룹 관리] → 방 이름.
2. 방에서 `.설정` → 설정 메뉴가 1:1 로 간다 (방 명령은 지워짐).
3. 방에 뜬 [⚙️ 봇 설정 (관리자)] 버튼.

## 주요 화면
- [🚀 빠른 설정]: 방 종류(소통방·거래방·게임방·공지방) 고르면 추천값 적용, 10분 안 되돌리기.
- [🧩 기능 켜기/끄기]: AI 대화·게임·스포츠 알림·일일 리포트·태그 알림.
- [🚪 입장·인사] · [🛡️ 보안] · [🔒 종류별 잠금] · [🚨 대량 입장 방어].
- [🤖 AI]: 말투·답변 길이·[🧠 기억·대화 방식]·[📚 학습 자료].
- [🗓️ 예약공지] · [🔔 알림 규칙] · [🎙 음성채팅] · [📜 규칙].
- [🛠️ 봇 관리자]: 텔레그램 관리자가 아닌 사람에게 소담 관리 권한 주기.
- [🧹 멤버 정리]: 탈퇴 계정·다른 봇·잠수·가라 의심 멤버를 골라 미리보기 → 확인 카드 → 한 명씩 내보내기 ('사용자 차단' 권한 관리자).
- [💳 이용 기간·구독]: 텔레그램 관리자에게만 보인다.

## 글로 바꾸기
- `.설정 전체` → 모든 설정 이름·값 목록.
- `.설정변경 이름 값` → 예: `.설정변경 style 맞받아치기`.
- 말로도 돼요 (방에서, 관리자): "소담아 링크 차단 꺼줘" · "사진·스티커 막아줘" · "퇴장 인사 켜줘" · "뉴스 알림 속보만" →
  바로 바뀌고 무엇이 바뀌었는지 답해요. 사진·영상 인사, URL 버튼은 1:1 편집기에서만.
- AI 대화를 끄면 소담이 말에 답하지 않으니 다시 켤 땐 `.AI대화 켜기` 나 메뉴 [🧩 기능 켜기/끄기].

## 조건·예외
- 설정은 방 관리자(텔레그램 관리자 + 봇 관리자)만. 결제·빠른 설정·봇 관리자 관리는 텔레그램 관리자만.
- 메뉴 버튼은 1:1 에서만 눌린다.
