## 한 줄 답
방을 **가입 승인** 방식으로 두고 [🤖 로봇 인증]을 켜면, 가입 신청한 사람에게 소담이 1:1 로 비뚤게 그린 숫자를 보내요. 숫자를 버튼으로 누르거나 채팅으로 보내서 맞히면 바로 들어와요.

## 켜는 법
1. 소담에게 관리자 권한 중 **'사용자 초대(Invite users)'** 를 켜 주세요. 없으면 가입 신청이 소담에게 안 와요.
2. 텔레그램 방 설정에서 **가입 승인(Approve new members)** 을 켜요. 또는 화면의 [🔗 승인제 초대링크 만들기] 로 만든 링크를 써요.
3. 소담 1:1 → 방 고르기 → [🤖 로봇 인증] → '가입 신청 1:1 확인' 버튼을 눌러 ✅ 로 켜고, 방식에서 [🔢 숫자 입력] 을 골라요.
4. [🧪 나한테 시험으로 받아보기] 로 신청자가 받는 화면을 미리 볼 수 있어요 (맞혀도 승인 안 함).
- 말로: "소담아 가입 신청 로봇 인증 켜줘" (관리자).

## 신청한 사람이 보는 것
- 숫자 4자리 그림(4~6자리로 바꿀 수 있음) + 숫자 버튼 판. 버튼으로 누르거나 1:1 채팅에 숫자만 보내면 돼요.
- 틀리면 새 숫자로 바뀌고, **3번** 틀리거나 제한 시간(입장 캡차 시간, 기본 5분)이 지나면 신청이 거절돼요. 다시 신청하면 돼요.
- 숫자가 잘 안 보이면 [🔄 새 숫자] (기회는 안 줄어요).

## 조건·예외
- 봇 계정은 바로 거절, 자유 멤버는 바로 승인, 스팸 명단·공동 차단 명단(켜 둔 방)은 거절해요.
- 1:1 을 받을 수 없는 사람은 그대로 두니 관리자가 직접 승인해 주세요.
- 통과한 사람은 들어온 뒤 방 캡차·대량 입장 내보내기를 건너뛰어요.
- 승인제가 아닌 링크·추가로 들어온 사람은 이 확인을 안 받아요 (그 사람들은 [🚪 입장·인사] 의 입장 캡차).
- 그림 버튼 방식([🖼 그림 버튼])도 있어요 — '강아지' 같은 그림 6개 중 하나 누르기.

## 소담이 하지 말 것
- '사용자 초대' 권한 없이 "켰으니 이제 돼요" 라고 하지 않기 — 권한부터 안내.
- 신청자 대신 숫자를 알려 주지 않기.
