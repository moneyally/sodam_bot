## 한 줄 답
`.명령어`로 전체 목록, `.도움말`로 "이렇게 말해 보세요" 예시를 봐요. 명령어 없이 "소담아 …"로 말해도 대부분 돼요.

관리자 명령도 말로도 돼요: "영희 내보내"(`.킥`) · "@abc 밴 풀어줘"(`.밴해제`) · "금지어에 먹튀 추가"(`.금지어`) ·
"방 잠가줘"(`.잠금`) · "예약 3번 꺼줘"(`.예약공지 끄기`). 제재·풀기·잠금·청소는 확인 카드를 눌러야 실행돼요.

## 누구나
| 명령 | 하는 일 |
|---|---|
| `.도움말` · `.명령어` | 말 예시 · 명령 전체 |
| `.내아이디` · `.내정보` | 내 숫자 ID · 내 활동 |
| `.기록` (답장/@/ID) | 이름·@아이디 변경 기록 |
| `.규칙` | 방 규칙 |
| `.랭킹` · `.통계` · `.검색 단어` | 채팅 순위 · 방 통계 · 대화 검색(30일) |
| `.말투 이름` · `.말투 도움말` · `.호칭 이름` | 나에게만 말투 · 말투 예시 · 부를 이름 |
| `.기억` · `.기억 지우기` | 소담이 기억한 내 정보 |
| `.게임 끝말잇기` · `.포인트` · `!도움` | 게임 |
| `.스포츠` · `.스포츠 순위 EPL` · `.스포츠 팀 토트넘` | 경기 일정·스코어·순위 (관리자: `.스포츠 구독 EPL`) |
| `.뉴스` · `.뉴스 경제` | 여러 해외 언론이 함께 다룬 주요 뉴스 |

| 명령 | 하는 일 |
|---|---|

| `.지식` · `.AI대화 켜기/끄기` · `.리포트` · `.관리기록` · `.멤버` | AI·기록 |

| `.멤버정리 중지/제외 @user/제외해제/제외목록` | 멈추기 · 안 내보낼 사람 |
| `.전체태그 [할 말]` | 전체 멤버 태그 (확인 카드·6시간 1번) |

## 조건·예외
- `.멤버정리`: '사용자 차단' 권한 관리자만, 명단은 1:1 로만. 관리자·14일 안에 글 쓴 사람·자유 멤버·제외 명단은 안 내보냄, 밴 아님(재입장 가능). 잠수 = 정확한 마지막 접속만. 오너는 1:1 에서 뒤에 방 이름.
- `.전체태그`: 5명씩, 10분 뒤 지움, 텔레그램 전체 명단 기준.
- 텔레그램 `/` 메뉴에도 주요 명령이 있다 (`/help` 등).
- 1:1 에서 안 되는 명령은 "그룹방에서 쓰는 명령어예요" 안내가 나온다.
