# words_ko.txt.gz — 끝말잇기 판정용 낱말 목록

한 줄에 한 낱말 (gzip). 앞에 `*` 가 붙은 것은 흔한 낱말 (봇이 이을 말로 고름).
표준어 명사(대명사·수사 포함) 325,973개 — 방언·옛말·북한어·띄어 쓰는 구·사전 외 낱말은 뺐다.

이 파일만 아래 라이선스를 따른다 (봇 코드의 라이선스와 별개):

- 국립국어원 《표준국어대사전》 — CC BY-SA 2.0 KR
  (https://creativecommons.org/licenses/by-sa/2.0/kr/)
- hunspell-dict-ko 낱말 데이터 (https://github.com/spellcheck-ko/hunspell-dict-ko) — CC BY-SA 4.0

가공: 41ways/kkeutmal 의 `dict/words.txt` (https://github.com/41ways/kkeutmal, MIT 코드 + 위 데이터 라이선스)에서
`!`(표준어만에서 막는 말)·`+`(사전 외 낱말) 표시가 붙은 줄과 한 글자 낱말을 빼고, `~`(외래어) 표시는 지웠다.
이 파생 목록도 CC BY-SA 4.0 으로 배포한다.
